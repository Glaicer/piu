# 36: Окно субагента сворачивает thinking и вызовы инструментов, как основной чат

**What to build:** В окне субагента (Modal из карточки `agent @id`) thinking-блоки и вызовы инструментов рисуются теми же компонентами, что в основном чате (`Thinking`, `ToolCard`): свёрнуты по умолчанию, раскрываются кликом или стрелками + Enter. Раньше окно писало мысли и результаты инструментов сплошным текстом. Продолжение 35: там сворачивание было вынесено за рамки.

**Blocked by:** None (35 done).

**Status:** done

## Критерии приёмки

- [x] Thinking-блок виден как `▸ Thinking` без текста; клик по нему раскрывает текст (`▾ Thinking`).
- [x] Вызов инструмента виден как карточка `▸ имя аргумент статус`, результат скрыт до раскрытия.
- [x] Стрелки двигают выбор по карточкам в видимой части, Enter раскрывает выбранную; за последней карточкой стрелки прокручивают, как раньше.
- [x] Текст ответа, сообщение пользователя и прокрутка окна не меняются (текст получил такие же отступы, как в чате).

### Проверки

## Comments

- Данные: запись инструмента в `SubagentEntry` теперь несёт `arguments` (объект, строковые и крупные значения обрезаны до 500 символов), а не строку `args` в 200 символов, потому что `ToolCard` показывает ключевой аргумент и JSON тела. Из обрезанной строки это не собрать.
- Для `ToolCard` окно собирает `call` и `result` из записи; длительности и фоновых заданий у вызова child'а нет, `abandoned` всегда `false` (вызов без результата у остановившегося child'а остаётся `running`, как было).
- Markdown для текста ответа в окне не подключён: просили только thinking и инструменты.
