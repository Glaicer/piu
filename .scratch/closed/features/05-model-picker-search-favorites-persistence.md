# 05: Поиск моделей, Favorites и сохранение модели с reasoning

**What to build:** В Modal выбора модели есть поле поиска и две вкладки `[Favorites | All]`. Модели добавляются в избранное и удаляются из него кликом по звёздочке или клавишей `F`. Избранное и последняя выбранная пара «модель + уровень reasoning» сохраняются между запусками piu и используются во всех проектах. Явные CLI-параметры и выбор в возобновляемой сессии имеют приоритет над сохранённым значением по умолчанию.

**Blocked by:** None (can start immediately).

**Status:** done

## Критерии приёмки

### Поиск и вкладки

- [x] Клик по текущей модели, `/model` и настроенная горячая клавиша открывают одну и ту же Modal с полем поиска и ровно двумя вкладками: `Favorites` и `All`.
- [x] `All` показывает доступные модели настроенного Backend, `Favorites` — избранные из этого же списка. Модель различается по паре `provider + model id`; одинаковые id у разных провайдеров не смешиваются. Провайдер виден в строке модели.
- [x] При открытии с непустым доступным избранным активна `Favorites`, иначе `All`. Поле поиска изначально пустое; текущая модель отмечена, если присутствует в списке активной вкладки.
- [x] Поиск без учёта регистра фильтрует модели по отображаемому имени, id и провайдеру в активной вкладке по мере ввода. Запрос сохраняется при переключении вкладок, очистка возвращает весь список вкладки. Пустое избранное и отсутствие совпадений показывают разные понятные состояния; Enter в пустом списке ничего не выбирает.
- [x] Вкладки, поле поиска и список доступны мышью и клавиатурой. Выделение остаётся на существующей строке после фильтрации или удаления из избранного; список прокручивается независимо, выделенная строка видна. Ввод поиска не попадает в prompt под Modal. Закрытие по Esc или клику снаружи возвращает фокус в prompt без смены модели.

### Favorites

- [x] В строке модели видна звёздочка, показывающая её наличие в избранном. Клик по ней переключает этот статус без выбора модели и закрытия Modal; в `Favorites` удалённая модель сразу исчезает из списка.
- [x] Клавиша `F` при фокусе в списке переключает избранное у выделенной модели точно так же, как звёздочка. Горячая клавиша указана в Modal. При фокусе в поле поиска буква `f`/`F` вводится в запрос и не переключает избранное.
- [x] Избранное сохраняется после каждого изменения и восстанавливается после закрытия Modal, полного завершения и нового запуска piu, в том числе в другой рабочей директории. Временно недоступная модель не становится выбираемой и не удаляется из сохранённого избранного автоматически.

### Модель и уровень reasoning

- [x] Выбор модели применяется через Backend, а показанные модель и уровень reasoning соответствуют его подтверждённому состоянию. После успешного выбора модели или изменения уровня через существующий reasoning picker сохраняется последняя фактическая пара. Отказ Backend показывает ошибку и не заменяет ранее сохранённый выбор отклонённым.
- [x] При следующем запуске piu в любом проекте сохранённая пара становится личным значением по умолчанию. Она восстанавливается до отправки первого сообщения модели, а не только отображается под полем ввода. Выбранная модель не обязана быть в `Favorites`.
- [x] Явные параметры модели и reasoning в CLI, включая `backend.args`, имеют приоритет для соответствующих полей; затем действует выбор возобновляемой сессии, затем сохранённый выбор piu, затем обычный выбор Backend. Сам запуск с CLI-переопределением или восстановление другой сессии не перезаписывает личное значение по умолчанию; оно меняется после следующего успешного выбора пользователем.
- [x] Если сохранённая модель недоступна, приложение запускается с доступным выбором Backend и сообщает, что восстановить модель не удалось. Если уровень reasoning не поддерживается, используется допустимый для фактической модели уровень и показывается именно он. Неудачное восстановление не стирает сохранённую пару.
- [x] Избранное и личный выбор хранятся вне репозитория в каталоге piu с учётом `PIU_HOME`. piu не переписывает ради этого Pi settings, `enabledModels`, credentials или Config. Ошибка записи видна пользователю и не выдаётся за успешное сохранение.
- [x] Несколько инстансов не меняют модель друг у друга во время работы. Изменение избранного в одном не стирает выбор модели, сохранённый другим, и наоборот; между запусками действует последний успешно сохранённый явный выбор.

### Проверки

- [x] Проверки через `startPiu` покрывают открытие всеми тремя способами, поиск в обеих вкладках, переключение вкладок с запросом, пустые результаты и выбор модели мышью и клавиатурой. Для звёздочки и `F` есть отдельные сценарии; ввод `f` в поиске не меняет избранное. Проверяется различие одинаковых model id у двух провайдеров.
- [x] Проверки с повторным запуском и тем же временным `PIU_HOME`, но другой рабочей директорией, подтверждают сохранение избранного и пары «модель + reasoning». Следующий запрос действительно получает выбранная модель с выбранным уровнем, что видно по её ответу. Отдельно проверяются CLI-приоритет, возобновление сессии со своим выбором, отказ смены модели, недоступная сохранённая модель, неподдерживаемый уровень и ошибка сохранения. Личные файлы Pi и piu пользователя не используются.

## Comments

- Пользователь выбрал отдельное избранное piu со звёздочками и общую для всех проектов последнюю пару «модель + reasoning». Дополнение пользователя: избранное переключается также горячей клавишей `F`.
- `F` действует в списке, чтобы не мешать поиску по названиям вроде `faux`. Переход между поиском и списком должен быть доступен клавиатурой; действие относится к выделенной строке, а не обязательно к текущей активной модели.
- Сейчас `builtin/model/index.tsx` строит обычный список из `context.pi.models`; `builtin/reasoning/index.tsx` открывает отдельный picker уровней. Общий `src/picker.tsx` используется и другими Modal: поисковое поле и вкладки этого тикета не должны появиться во всех picker автоматически.
- В установленном Pi 1.5.0 RPC `set_model` и `set_thinking_level` вызывают методы сессии без `persist: true` (`dist/modes/rpc/rpc-mode.js`, `dist/core/agent-session.js`). Выбор записывается в историю сессии, но это само по себе не сохраняет defaults для новых запусков. Подтверждение по RPC и сохранение личного выбора piu — разные действия; использовать Pi в процессе приложения нельзя (ADR-0001).
- `Favorites` не является алиасом `enabledModels` или `--models` и не меняет их. Отдельные предпочтения reasoning для каждой модели, синхронизация избранного с обычным Pi и переделка интерфейса reasoning picker в этот тикет не входят.

- Проверка `pnpm check`: 360 тестов прошли; два существующих сбоя воспроизведены на чистом `HEAD`: компакция в `test/polish.test.ts` и нестабильный `steer` в `test/pending.test.ts`. Затронутые `test/modal.test.ts` и `test/lifecycle.test.ts`, типизация и Biome проходят.
