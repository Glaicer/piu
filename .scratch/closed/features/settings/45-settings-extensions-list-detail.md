# 45: Вкладка Extensions: список слева, карточка справа

**What to build:** Вкладка «Extensions» в Settings (тикеты 29–31) переходит с одной длинной строки на расширение на раскладку «список + карточка» (вариант B прототипа). Слева узкий список с группами Agentic / Interface: значок состояния и имя. Справа карточка выбранного расширения: имя, откуда оно (`file: …`, `package: …`, `builtin`, `personal`), состояние, пометки (`+ Pi extension`, `not placed`, `required`, несохранённое изменение) и кнопки «Disable/Enable» и «Delete/Undo delete». Карточка остаётся на виду при прокрутке списка.

Описаний расширений в этом тикете нет: пользователь решил сначала сделать вёрстку, источник описаний — отдельным тикетом.

## Критерии приёмки

- [x] Строка списка: значок состояния (`●` включено, `○` выключено, `✕` помечено к удалению) и имя; `*` у несохранённого изменения. Происхождение и кнопки в строке не показываются.
- [x] Карточка показывает выбранное расширение: имя, происхождение, состояние и пометки; кнопки — только доступные действия (у required и unavailable нет переключателя, у неудаляемых нет Delete). Для пакета кнопка называет пакет.
- [x] Выбор мышью и ↑/↓ меняет карточку; Enter/Space и Del работают как раньше; черновик, Save, подтверждения и Restart не меняются.
- [x] Карточка видна, когда выбранная строка внизу длинного прокрученного списка.
- [x] Прототип сохранён в ветке `prototype/settings-extensions-tab`.

### Проверки

- [x] Тест: при height=24 и 30 файлах выбор последней строки клавишами оставляет карточку этой строки в кадре.
- [x] Существующие тесты `settings-extensions` и `settings-extension-edits` читают происхождение и состояние из карточки и жмут кнопки в ней.

## Comments

Prototype: ветка `prototype/settings-extensions-tab` (коммит `5145036`), три варианта: A — таблица, B — список + карточка, C — двухстрочные строки. Пользователь выбрал B.

Отклонения и решения при реализации:

- Выбранное расширение хранится в черновике вкладки по ключу, а не индексом в представлении: после Save без Restart список перечитывается, и выбор остаётся на той же строке.
- Заголовок Agentic и ошибка чтения Pi settings стоят на всю ширину над списком, иначе текст ошибки переносился в узкой колонке.
- Карточка не уходит из вида так: хук `renderBefore` строки «список + карточка» сдвигает карточку (`translateY`) на `scrollTop` общего scrollbox вкладки. Отдельный scrollbox не заводили (тикет 29). Мутация (сдвиг 0) роняет тест «The details stay in view…».
- Кнопки: `Disable`/`Enable` (у пакета — `Disable package`/`Enable package`) и `Delete`/`Undo delete`. Строка списка помечается `*` при любом несохранённом изменении.
- Тесты читают происхождение и состояние из карточки через `selectExtension`/`extensionDetails`/`clickExtensionAction` в `test/harness.ts`; правило записано в `docs/agents/testing.md`.

Проверки: `pnpm typecheck` и `biome check` по изменённым файлам чистые; полный `bun test` — 793 pass, 0 fail; `settings-extensions` и `settings-extension-edits` прогнаны 10 раз подряд без падений. `pnpm check` по-прежнему падает на lint в старых `test/zz-debug*.test.ts` из HEAD (см. тикет 29).

Дополнение после закрытия: у Extensions piu появились описания. Инвентарь читает `description` из `<папка Extension>/package.json`, не импортируя её код, поэтому описание видно и у неразмещённых. Карточка показывает его под именем. У всех десяти встроенных Extensions теперь есть `package.json` с `description`; соглашение описано в `docs/extensions.md`. У Pi extensions (Agentic) описаний пока нет.
