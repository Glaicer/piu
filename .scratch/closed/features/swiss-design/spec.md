# Swiss design

Новый вид piu: белый фон, чёрный текст, красный только для того, что происходит прямо сейчас, плюс подсветка кода. Утверждённый макет светлой темы: `mockup/swiss-light.png` (в терминале: `cat mockup/swiss-light.ans`, окно не уже 116 колонок; генератор `mockup/swiss-light.js`).

Утверждённый макет тёмной темы: `mockup/swiss-dark.png` (`cat mockup/swiss-dark.ans`; генератор `mockup/swiss-dark.js` рисует три варианта, выбран третий, «graphite quiet»).

Тикеты: 37 палитра и подсветка → 38 Panels без рамок → 39 нижняя строка → 40 поле ввода → 41 блоки чата → 42 Modals, Toasts, список `/` (сначала макет) → 43 тёмная тема (сначала макет).
