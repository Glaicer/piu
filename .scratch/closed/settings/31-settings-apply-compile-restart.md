# 31: Применение Settings: компиляция Pi-Bolt и Restart

**What to build:** После «Сохранить» в Settings, если список extensions изменился, piu сам применяет изменения: определяет семейство Backend; если это Pi-Bolt и изменилась группа Agentic, запускает `pi-bolt compile`; затем перезапускает Backend и себя с той же сессией. Пользователь видит, что идёт (компиляция, перезапуск), и получает результат.

**Blocked by:** 30 (включение, выключение и удаление extensions в Settings).

**Status:** done

## Решения

- **Семейство Backend — только из вывода `backend.command` с `backend.args` и `--version`**, как везде в piu: `1.5.2 (Pi-Bolt 1.2.1, …)` — Pi-Bolt, просто версия — Pi. Не по PATH, `node_modules` или `compile.json`.
- **Компиляция — только для Pi-Bolt и только если изменилась группа Agentic.** Изменения Interface грузятся из файлов (`-e`), им достаточно Restart.
- **Компиляция запускается через настроенный `backend.command`** (`<backend> compile`), а не через `pi-bolt`, найденный в PATH, — то же правило, что для определения семейства.
- **Компиляция заменяет исполняемый файл**, поэтому идёт под той же блокировкой установки, что и обновление Backend, и не начинается, пока идёт обновление. Если piu закрывают во время компиляции, она доводится до конца, как установка обновления.
- **Ошибка компиляции не отменяет Restart.** По документации Pi-Bolt изменённый после компиляции Pi extension грузится из файлов с предупреждением, а выключенный или удалённый не грузится вовсе, даже если вкомпилирован. Поэтому при ошибке piu показывает предупреждение и где лежит лог компиляции, и всё равно перезапускается; новые настройки действуют, теряется только скорость.
- **Restart — через `actions.restart`**, так что сессия продолжается, как при `/restart`.
- **Если идёт ход агента**, piu спрашивает подтверждение до Restart: перезапуск его прервёт. Отказ оставляет изменения записанными; они вступят в силу при следующем Restart, и piu это говорит.

## Критерии приёмки

- [x] Изменились только Interface: piu перезапускается без компиляции.
- [x] Изменились Agentic, Backend — Pi: piu перезапускается без компиляции.
- [x] Изменились Agentic, Backend — Pi-Bolt: piu запускает `pi-bolt compile`, показывает, что идёт компиляция, и после неё перезапускается.
- [x] Ошибка компиляции: предупреждение с путём к логу, затем Restart.
- [x] Компиляция не начинается, пока держится блокировка обновления Backend; piu говорит, что ждёт.
- [x] Во время хода агента Restart начинается только после подтверждения.
- [x] После Restart сессия та же, что до сохранения.

### Проверки

- [x] Проверка через `startPiu` с подставным Backend, который печатает версию Pi-Bolt и записывает вызов `compile` в файл: изменение Agentic вызывает `compile` ровно один раз, затем Restart; изменение только Interface — без `compile`.
- [x] Та же проверка с Backend, печатающим версию Pi: `compile` не вызывается.
- [x] Проверка: подставной `compile` завершается с ошибкой — предупреждение показано, Restart произошёл.
- [x] Тесты никогда не запускают настоящий `pi-bolt compile` и не трогают настоящий agent dir.

## Comments

- Ошибка компиляции не перезапускает piu сразу: иначе предупреждение пропало бы вместе с приложением. piu показывает подтверждение с предупреждением и путём к логу, по умолчанию выбран «Restart now», так что Enter перезапускает. Отказ оставляет изменения записанными, и piu говорит, что они вступят в силу после Restart.
- Лог — собственный файл piu `$PIU_HOME/pi-bolt-compile.log` с полным выводом `<backend> compile`, а не `compile.log` Pi-Bolt, который лежит во временной папке компиляции.
- Семейство Backend определяется в worker'е компиляции под блокировкой установки, поэтому при Pi worker тоже запускается, но `compile` не вызывает. `compile` запускается тем же способом, что `remove` (`backendSubcommand`): аргументы RPC из `backend.args` отбрасываются.
- Ход агента проверяется после компиляции, прямо перед Restart. Если ход идёт, подтверждение по умолчанию на «Cancel».
- После «Сохранить» piu теперь перезапускается, поэтому тесты тикета 30 переписаны на несколько запусков, а `startPiu` больше не перезаписывает `agent/settings.json` в повторно используемом `dir`.
- Не проверено тестом: что компиляция доходит до конца, если piu закрыть во время неё (worker отсоединён, как worker обновления). Не проверено на настоящем Pi-Bolt: тесты запускают только подставной `compile`.
