# 27: `/context injections` — что попало в запрос

**What to build:** `/context injections` открывает в Modal список скрытых частей последнего запроса к модели: системный промпт по разделам, определения tools и то, что добавили Pi extensions, включая правки, которые они вносят только в запрос к модели. Выбор строки показывает её полный текст. После этого тикета пакет `pi-context-view` больше не нужен.

**Blocked by:** 26 (`/context` — расход контекста).

**Status:** ready-for-agent

## Критерии приёмки

- [ ] Список содержит разделы системного промпта, каждое определение tool и каждый вклад Pi extension в последний запрос, с размером в токенах.
- [ ] Выбор строки (Enter или клик) показывает полный текст; Esc возвращает к списку, второй Esc закрывает Modal.
- [ ] Правки, которые Pi extension внёс только в запрос к модели (а не в сессию), видны и помечены.
- [ ] До первого запроса Modal говорит, что запроса ещё не было.
- [ ] Переключение между usage и injections внутри одного Modal работает без повторного ввода команды.

### Проверки

- [ ] Проверка через `startPiu` с faux model и тестовым Pi extension, который добавляет раздел в системный промпт в `before_agent_start`: после хода раздел есть в списке, его текст открывается.
- [ ] Проверка: список tools совпадает с tools, которые faux model получила в запросе.

## Notes

- Как `pi-context-view` ловит итоговый запрос (порядок хуков, захват до и после чужих Pi extensions), посмотреть в его исходниках в установленном пакете и повторить только нужное.

## После приёмки (вручную)

- [ ] Удалить пакет `pi-context-view` (`pi-bolt remove npm:pi-context-view`) и пересобрать Pi-Bolt (`pi-bolt compile`).
