# 32: Modal «Settings» с вкладками и вкладка Global

**What to build:** Команда `/settings` открывает Modal «Settings»: большое окно по центру с полосой вкладок. Каждая вкладка — отдельная часть, и любая Extension может добавить свою. Вначале вкладка одна, Global, на ней две настройки: Theme (`auto` / `light` / `dark`) и Animations (вкл/выкл). Изменение сразу применяется и записывается в личный Config. Вкладка «Extensions» появится в тикете 29 через тот же механизм вкладок.

**Blocked by:** 22 (Modal с размером в процентах терминала).

**Status:** ready-for-agent

## Решения

- **`/settings` — встроенная команда**, как `/restart` и `/update` (`src/lifecycle-commands.ts`), а не часть Extension. Она есть в `/` при любом Placement.
- **Вкладку добавляет Extension** через новое необязательное поле `Extension` (рядом с `commands`). Вкладка показывается, когда Extension загружена: по тому же правилу, по которому её команды попадают в `/`. Встроенные вкладки (Global, позже Extensions) задаются тем же типом, что и вкладки Extensions, и видны всегда.
- **Порядок вкладок:** сначала встроенные (Global, затем Extensions из тикета 29), потом вкладки Extensions в порядке их загрузки. Открывается первая вкладка.
- **Theme хранится в `theme.mode`:** `"auto" | "light" | "dark"`, по умолчанию `"auto"`. Ключ `theme` уже занят заменами цветов по токенам, поэтому режим ложится в тот же объект рядом с ними: замены цветов работают как раньше и накладываются на выбранную тему. `auto` — нынешнее поведение (тема следует режиму терминала), `light` и `dark` фиксируют тему и не реагируют на смену режима терминала.
- **Global применяет изменения сразу, без черновика и кнопки «Сохранить».** Результат виден мгновенно, Restart не нужен. Черновик с «Сохранить» остаётся только у вкладки «Extensions» (тикет 30), где без Restart ничего не применяется.
- **Запись в личный Config (`PIU_HOME/config.json`) здесь происходит впервые.** Перед записью файл перечитывается, меняется только нужный ключ, остальные ключи сохраняются, файл записывается атомарно. Если файла нет, он создаётся. Это решение записать как ADR в `docs/adr/`; тикет 30 дополнит этот же ADR записью в Pi settings.

## Критерии приёмки

- [ ] `/settings` есть в `/` всегда и открывает Modal «Settings» по центру, размером 75% ширины и высоты терминала (как окно субагента из тикета 22). Окно пересчитывается при изменении размера терминала.
- [ ] Modal закрывается Esc и кликом вне него; содержимое вкладки прокручивается, если не помещается.
- [ ] Полоса вкладок: вкладку можно выбрать кликом и с клавиатуры. Клавиши выбрать в плане по `docs/agents/opentui.md` так, чтобы они не мешали input внутри вкладки.
- [ ] Личная Extension во `PIU_HOME` может добавить вкладку без правки кода piu; вкладка появляется после встроенных.
- [ ] Global: Theme переключается между `auto`, `light` и `dark`, цвета всего экрана меняются сразу. Замены цветов из `theme` продолжают действовать.
- [ ] Global: Animations включаются и выключаются без Restart. Как ведут себя уже идущие циклические анимации (например, спиннер хода агента), решить в плане и записать в `## Comments`.
- [ ] Каждое изменение в Global записывается в личный Config; после Restart настройка та же. Все остальные ключи личного Config остаются на месте, а сам файл остаётся читаемым человеком (с отступами).
- [ ] Если личный Config за время работы стал невалидным JSON, piu не перезаписывает его: изменение применяется только до Restart, а Toast говорит, что записать не удалось.
- [ ] Config разбирает `theme.mode`; неизвестное значение — ошибка запуска с путём `theme.mode`.
- [ ] `docs/extensions.md` описывает, как Extension добавляет вкладку в Settings.
- [ ] `GLOSSARY.md`: сейчас Config запрещает слово «Settings» как занятое настройками Pi. Пользователь выбрал «Settings» как имя Modal; добавить термин для Modal (и вкладки), а Pi'шные называть «Pi settings».
- [ ] Значения по умолчанию в репозитории не меняются: `theme.mode` — `auto`, `animations` — `true`.

### Проверки

- [ ] Проверка через `startPiu` с временным `PIU_HOME`: `/settings` открывает Modal с вкладкой Global; переключение Theme на `light` меняет цвета в кадре и пишет `theme.mode` в личный Config, не трогая заранее записанный там другой ключ.
- [ ] Проверка: выключение Animations пишет `"animations": false`; после Restart Global показывает выключенные анимации.
- [ ] Проверка с личной Extension, которая добавляет вкладку: вкладка видна и открывается.
- [ ] Проверка: при невалидном личном Config изменение не пишет файл и показывает Toast.
- [ ] Проверки разбора Config: `theme.mode` с каждым из трёх значений, отсутствие ключа, неверное значение.
- [ ] Тесты не читают и не пишут настоящий `~/.piu`.

## Notes

- `writeJson` (`src/json-file.ts`) уже пишет атомарно, но в одну строку. Для личного Config, который человек правит руками, нужны отступы.
- Сейчас `animations` читается один раз при старте (`createAnimate` в `src/app.tsx`), а тема собирается в `createTheme` (`src/theme.ts`) из режима терминала и замен цветов. Обе настройки надо сделать изменяемыми во время работы.
- Выбор модели в Settings не входит: `/model` остаётся отдельной Modal.
