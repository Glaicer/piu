# 41: Swiss: блоки чата

**What to build:** Блоки чата как в макете. Сообщение пользователя жирным на сером фоне `raised` с серой подписью `you` справа. `▸ Thinking` курсивом. Вызовы инструментов идущие подряд стоят плотной группой без пустых строк: чёрный чип с именем, аргумент обычным текстом, справа статус точкой. Пустой экран без синего: заголовок чёрным жирным.

**Blocked by:** 37.

**Status:** ready-for-agent

## Решения

- **Сообщение пользователя:** заливка `raised` (уже так), текст жирный `text`, справа в той же строке `you` цветом `faint`. Многострочное сообщение: `you` на первой строке.
- **Thinking:** `▸`/`▾` цветом `faint`, `Thinking` курсивом `muted`. Длительности нет: в состоянии Pi её нет, выдумывать не надо.
- **Инструменты:** чип ` name ` фон `text`, текст `surface`, жирный (уже почти так). Аргумент цветом `text`, не `muted`. Справа:
  - готово: `●` и длительность цветом `faint`;
  - идёт: `◐ running` цветом `signal`;
  - ошибка: `● error` и длительность цветом `error`;
  - фоновые задания (`launchedJobId`): прежние подписи статуса, цвет по тем же правилам.
- **Группа:** `marginTop` у карточки инструмента только когда перед ней не карточка инструмента. Раскрытое тело карточки по-прежнему отделено пустой строкой.
- **Пустой экран:** заголовок `text` жирный вместо `accent`.
- **Карточки субагентов и Backend** (`subagent-card.tsx`, `backend-card.tsx`) переводятся на те же цвета статусов.

## Критерии приёмки

- [ ] Сообщение пользователя жирное на сером фоне, `you` справа серым.
- [ ] Три вызова инструментов подряд занимают три строки подряд; у завершённых серые `●` и длительность, у идущего красный `◐ running`, у упавшего красный `● error`.
- [ ] Клик или Enter по строке инструмента раскрывает тело, как раньше.
- [ ] `▸ Thinking` курсивом, без длительности.
- [ ] Заголовок пустого экрана чёрный жирный.
