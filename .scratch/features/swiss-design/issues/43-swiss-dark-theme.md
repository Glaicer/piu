# 43: Swiss: тёмная тема

**What to build:** Тёмная тема в системе Swiss по утверждённому макету `mockup/swiss-dark.png` (вариант «graphite quiet»): та же раскладка, что у светлой, графитовый фон `#121212`, светлый текст, красный только для живого, нижняя строка тёмно-серая (не светлая инверсия). Подсветка кода в осветлённых тонах.

**Blocked by:** 37, 39 (токены), 41 (цвета блоков чата). Можно делать после 37 и дополнять по мере 38–41.

**Status:** ready-for-agent

## Решения

- **Выбор пользователя:** из трёх тёмных вариантов (`swiss-dark.js`: чистый чёрный с белой нижней строкой, графит со светлой, графит с тёмной) выбран третий.
- **Значения `darkTheme`** (`src/theme.ts`):

  | Токен | Цвет |
  | --- | --- |
  | `background`, `surface` | `#121212` |
  | `raised` | `#222222` |
  | `text`, `accent` | `#ececec` |
  | `muted` | `#a8a8a8` |
  | `faint` | `#6f6f6f` |
  | `border` | `#2e2e2e` |
  | `selection` | `#2a2a2a` |
  | `signal`, `error` | `#ff453a` |
  | `secondary` | `#6ea8ff` (inline-код `#7fb2ff` в макете, свести к одному) |
  | `tertiary` | `#c58af9` |
  | `success` | `#5fd38d` |
  | `warning` | `#ffa04d` |
  | `code` | `#1b2333` (inline-код, синеватый) |
  | `codeBlock` | `#1a1a1a` (блок кода, нейтральный) |
  | `bar`, `barText`, `barMuted` | `#262626`, `#ffffff`, `#a8a8a8` |

- **Чипы инструментов** инвертированы автоматически (фон `text`, текст `surface`): светлые с тёмным текстом.
- **Подложки кода разные (решение пользователя):** блок кода нейтральный (`codeBlock`), inline-код синеватый (`code`), в обеих темах.
- **Затемнение под Modal** (тикет 22) проверить на графитовом фоне: Modal должен оставаться отличимым.

## Критерии приёмки

- [ ] На тёмном терминале экран совпадает с `mockup/swiss-dark.png` по цветам: графитовый фон, светлый текст, красные `›`, курсор, маркеры и `running`, тёмно-серая нижняя строка с белой моделью.
- [ ] Подсветка кода, inline-код и `**…**` различимы так же, как в светлой теме.
- [ ] Терминал, который не сообщил фон, получает тёмную тему, как сейчас.
- [ ] Modals, Toasts и список `/` после тикета 42 читаемы в тёмной теме.
