## Макет (утверждён 2026-11-16)

`mockup/swiss-modals-light.png` (в терминале: `cat mockup/swiss-modals-light.ans`, окно не уже 116 колонок; генератор `mockup/swiss-modals-light.js`). Четыре кадра: выбор модели + Toast info; Dialog select + Toasts info и error стопкой; Dialog confirm + Toast warning; список `/` над полем ввода. Что предлагает макет:

- **Modal:** фон `surface` (белый) вместо `raised`, без рамки; верхний ряд — жирная линия `━` цвета `text`, во втором ряду жирный заголовок и справа `esc` цветом `faint`. Отступы рамки те же (3/1/3/2), так что высоты Modals не меняются. Затемнение под Modal остаётся.
- **Dialogs:** заголовок переезжает в рамку (на место заголовка Modal), `message` у `confirm` цветом `muted` под ним.
- **Выделенная строка** везде (Picker, выбор модели, Dialogs, список `/`): фон `text` (чёрный), текст белый жирный, детали `#bdbdbd`.
- **Выбор модели:** вкладки без фона, активная жирная чёрная с `━` под ней, под всей строкой вкладок тонкая `─` цвета `border`; поиск как поле ввода: `›` и курсор цветом `signal`, плейсхолдер `search models` цветом `faint`; ☆ цветом `faint`, ★ цветом `text`; текущая модель помечена словом `current` цветом `faint` вместо ` *`; подсказки в стиле поля ввода (`tab search/list   ←/→ tabs   f favorite   ⏎ pick`).
- **Toasts:** сплошной блок в 3 ряда без рамки, белый текст; info на `text` (чёрный), error на `error`, warning на `warning`.
- **Список `/`/`@`:** подложка `raised` без рамки, верхний ряд — `━` цвета `text`; метка жирная чёрная, описание `muted`.

## Comments

- **Заголовок Dialog не переехал в рамку**, как в макете: заголовок бывает многострочным (команда на подтверждение), а рамка рисует одну строку. Вместо этого Modal, у Module которого нет `title` (Dialogs, окно субагента), оставляет сверху один ряд вместо трёх, и Module сам рисует жирный заголовок в ряду заголовка, с переносом и отступом справа под `esc` (`untitledModalFrameRows`, `modalHintColumns` в `src/layout.tsx`). Визуально совпадает с макетом. Заголовок окна субагента (`agent @id …`) стал жирным, под ним пустой ряд.
- Цвета выделенной строки — токены `bar`/`barText`/`barMuted` (в светлой теме ровно #000/#fff/#bdbdbd из макета). Текст Toast — `background`, фон info — `text`. Активная вкладка и заголовки — `accent` (в светлой теме чёрный), так тест на замену `accent` в Config остался осмысленным.
- В тёмной теме изменения тоже видны (Modal на `surface`, инвертированные Toasts и строки); её дизайн в 43.
- `›` в поиске моделей бледнеет, когда фокус уходит в список, как в поле ввода; курсор поиска теперь `signal` (тест в `theme.test.ts` обновлён).
- Полоса прокрутки списка моделей: бегунок `text` на фоне `surface`, без тонкой линии трека из макета.
- Harness ищет Modal по раскладке (id `modal:<n>`) и проверяет заливку `surface`: тёмный `surface` совпадает с заливкой незатемнённых Panels, поэтому по одному цвету Modal больше не найти.
- `pnpm check`: два теста `/tree` в `test/session.test.ts` падают и на чистом HEAD (6449c07).
