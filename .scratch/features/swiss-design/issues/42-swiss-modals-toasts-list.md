# 42: Swiss: Modals, Toasts и список `/`

**What to build:** Modals (выбор модели, reasoning, Dialogs, changelog, окно субагента), Toasts и список автодополнения `/`/`@` выглядят в той же системе Swiss. Сначала макет в терминале (как `mockup/swiss-light.ans`), пользователь утверждает, потом код.

**Blocked by:** 38, 40.

**Status:** needs-info

## Решения

- **Порядок (согласовано с пользователем):** макет → утверждение → реализация. До утверждения код не меняется.
- **Что показать в макете:** выбор модели (вкладки, поиск, список, выделенная строка, звезда), Dialog `select` и `confirm`, Toast info и error, список `/` над полем ввода. Отправная точка для обсуждения: белый фон, жирная чёрная линия `━` сверху, жирный заголовок, выделенная строка чёрным фоном с белым текстом, Toast чёрным блоком (error красным). Это предложение, а не решение.
