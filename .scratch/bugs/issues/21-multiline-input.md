# 21: Многострочный ввод — курсор, прокрутка и стрелки

**Status:** needs-triage

## Как воспроизвести

1. Вставить многострочный текст в input.
2. Попробовать перемещаться по строкам клавишами ArrowUp и ArrowDown, в том числе когда текст не помещается в поле целиком.

## Фактическое поведение

- После вставки многострочного текста курсор отображается не там, где находится позиция ввода: на [скриншоте](21-multiline-input.png) он уехал ниже поля input.
- Прокрутки не видно.
- ArrowUp вместо перемещения по тексту открывает выбор предыдущей команды или предыдущего промпта.

## Ожидаемое поведение

- [ ] После вставки курсор отображается в правильной позиции внутри input.
- [ ] При переполнении input прокрутка видна и позволяет ориентироваться в тексте.
- [ ] При непустом input ArrowUp и ArrowDown не открывают историю команд или промптов; если строк несколько, клавиши перемещают курсор по строкам.

## Comments

- Скриншот приложен к сообщению об ошибке.
